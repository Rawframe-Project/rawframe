# Rawframe

Rawframe is a general-purpose, performance-oriented, network-first engine and toolchain for 2D and 3D games and real-time simulations.

The project is currently in its foundation phase. Architecture, product boundaries, programming models, build policy, security, platform support, and development workflow are specified before implementation directories are created.

No source layout is implied by this initial directory structure. Runtime, editor, SDK, toolchain, and module directories will be created only after their ownership and dependency model is accepted.
